## 🚀 Быстрый старт

### Только фронтенд (без сервера)
Просто откройте `frontend/index.html` в браузере.
Форма отправляет заявки напрямую в Telegram через браузер.

**Настройте в `frontend/js/main.js`:**
```js
const TG_BOT_TOKEN = 'ВАШ_ТОКЕН';
const TG_CHAT_ID   = 'ВАШ_CHAT_ID';
```

### С backend сервером (рекомендуется)
```bash
cd backend
npm install
# Отредактируйте .env
npm run dev   # или npm start
```

Сайт: http://localhost:3001

## 🤖 Настройка Telegram бота

1. Откройте @BotFather в Telegram
2. Создайте бота: `/newbot`
3. Скопируйте токен
4. Напишите боту что-нибудь
5. Перейдите: `https://api.telegram.org/botТОКЕН/getUpdates`
6. Найдите `"chat":{"id":XXXXXXX}` — это ваш CHAT_ID

**Или используйте @userinfobot для получения вашего chat_id.**
